什么是 AI 智能体？

不只是聊天机器人——AI 智能体是能调用工具、读写文件、执行命令、与外部系统交互的自主代理。

🤖

对话 → 行动

传统 AI 只能回答问题。智能体可以直接执行任务：写代码、创建文件、搜索网络、操作数据库，甚至控制浏览器。

🔧

工具调用

智能体通过 Tool Use 协议调用各种工具——文件读写、Shell 命令、API 请求，让 AI 从"说"变成"做"。

🧩

可扩展能力

通过 Skills（自定义技能）和 MCP（模型上下文协议），可以无限扩展智能体的能力边界，让它成为真正的个人助手。

🧠

上下文记忆

智能体可以记住项目结构、编码规范、用户偏好，甚至跨会话保存知识，越用越懂你。

agent-workflow.md
## AI 智能体工作流 用户: "帮我做一个网页" ↓ 智能体: 理解需求 → 规划结构 ↓ 工具调用: read_file, write_file, edit ↓ 技能加载: frontend-design skill ↓ 外部服务: MCP → WebSearch (查资料) ↓ 部署: git add → commit → push → GitHub Pages ↓ 用户: 收到在线链接 ✅
02

Qwen Code 使用经验

Qwen Code 是阿里通义千问推出的 CLI 智能体，在终端中直接与代码和项目交互。以下是日常使用中的核心场景和技巧。

日常开发

代码编写与重构

直接描述需求，智能体自动分析项目结构、遵循现有代码风格进行编写。

  • 自动识别框架和依赖
  • 遵循项目命名规范和代码风格
  • 一次性修改多个关联文件
  • 自动生成测试代码
项目管理

文件与 Git 操作

从创建文件到提交代码，智能体可以完成完整的项目管理流程。

  • 批量创建/重命名/移动文件
  • 自动 git add、commit、push
  • 处理合并冲突
  • 跨目录批量替换内容
文档处理

多格式文档生成

通过 Skills 扩展，可以生成 Word、PPT、PDF、Excel 等专业文档。

  • 学术专著排版与引用管理
  • PPT 演示文稿自动生成
  • 会议纪要从语音转写生成
  • 数据清洗与 Excel 报表
效率技巧

高效使用方法

掌握这些技巧可以大幅提升与智能体协作的效率。

  • 用 QWEN.md 定义项目规范
  • 复杂任务先让它出方案再执行
  • 善用 /review 做代码审查
  • 并行任务用 agent 分发给子代理

Skills · 自定义技能

Skills 是 Qwen Code 的扩展机制——用 Markdown 编写技能描述，让智能体在特定场景下自动加载专业能力。边做边写，逐步积累。

skill-structure.md — Skill 文件结构
## 一个 Skill 由以下部分组成： skill.md # 技能描述与触发规则（必须） reference.md # 详细参考文档（可选） scripts/ # 辅助脚本（可选） evals/ # 测试用例（可选） ## 触发方式 自动触发: 根据 description 中的关键词匹配 手动触发: 用户输入 /skill-name ## 存放位置 ~/.qwen/skills/your-skill/ # 用户级（跨项目） .qwen/skills/your-skill/ # 项目级（仅当前项目）

06

心得与体会

使用 AI 智能体这段时间的一些思考和经验总结。

💡 关键认知

🎯

提示词即接口

与智能体沟通就像设计 API——越清晰的输入，越稳定的输出。学会把模糊需求拆解为具体指令是核心技能。

🔄

迭代优于完美

不要期望一次对话就得到完美结果。先让 AI 出初版，然后逐步反馈调整，效率远高于反复修改提示词。

🧩

Skills 是复利

每写一个 Skill，后续所有类似任务都受益。投入时间编写和维护 Skills，长期回报巨大。

🌐

MCP 打破边界

接入外部服务后，AI 不再是封闭系统。地图、搜索、数据库、API——一切都可以成为智能体的"手和眼"。

📋

QWEN.md 很重要

项目规范文件让智能体理解你的代码风格、部署流程、常用路径。花 10 分钟写清楚，省下无数次解释。

⚡

人机协作 > 全自动

最好的模式不是完全交给 AI，而是人做决策和审核，AI 做执行和加速。保持对输出的判断力。
